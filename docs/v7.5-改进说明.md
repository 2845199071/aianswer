# v7.5 五项改进说明

> 对应上一轮评测里列出的 1~5 条建议。全部落地并验证，第 6 条（题库题数 1219 vs 1177）未做。

## 一、倒计时自动提速

**问题**：投票 3 家串行最坏 13 秒，考试倒计时里等不起。

**做法**：读屏时顺带扫屏幕文字，命中倒计时就进入「抢答模式」：

| 参数 | 平常 | 倒计时 |
|---|---|---|
| 投票家数 | 最多 3 家 | 最多 2 家 |
| 投票总预算 | 9 秒 | 4.5 秒 |
| 在线重试 | 失败换一家（最多 2 家） | 只试 1 家就回退本地 |

**判定规则**（`TimerDetect`，纯 Java 可单测）：
- 认：`03:04`、`剩余 12 秒`、`倒计时`、`距结束`、`考试剩余`
- **不认**：`已用 28:39`、`总用时 05:12` —— 正计时不会把人逼到超时，误提速只会让人困惑
- 长于 40 字的句子直接跳过（那是题干/材料，不是计时器）

悬浮窗第二行会出现「抢答模式（检测到计时器）」。

## 二、厂商按健康度动态排序

**问题**：智谱免费档的 1305 过载是常态，写死顺序 = 每题先白等它 4~5 秒。

**做法**：`CloudSolver` 记录每家的成功次数、失败次数、平均耗时（指数平滑），排序规则：

1. 冷却中的厂商永远排最后
2. 其余按成功率降序（贝叶斯平滑，没样本时 0.5）
3. 成功率相同按平均耗时升序
4. 全都相同则保持用户配置顺序（稳定排序）

排序结果用于两处：投票选哪几家、单模型失败时下一家试谁。

**顺带修的**：以前只问 `Prefs.provider()` 这一家，它一过载就直接掉本地。现在失败会换下一家健康的，来源里注明「第 2 家才成」。

## 三、思考中也避让

**问题**：避让只在出答案后触发，「思考中…」那几秒窗口照样压着题干。

**做法**：读屏一成功就调用 `avoidOptions(r)`，答案回来时窗口已经站好位置，不用二次挪动。

配合 v7.3 加的题干坐标避让，现在避让矩形 = 题干 + 所有选项。

## 四、告警写在外框上

**问题**：「只剩一家」「分歧」只在 meta 小字里，扫一眼看不出来。

**做法**：`Result.warnLevel` 由引擎给出，`QService` 取「分歧/低置信/引擎告警」三者最高值决定外框：

| 级别 | 场景 | 外框 |
|---|---|---|
| 0 | 正常 | 蓝（1dp） |
| 1 | 只剩一家可用 / 在线失败回退本地 / 低于阈值 | 黄（2dp） |
| 2 | 投票分歧（各家答案不同） | 红（2dp） |

## 五、导出未命中题

**问题**：题库没有、全靠模型答的题，每次都白花一次调用。

**做法**：`MissLog` 记录这些题的题干 / 选项 / 答案（只留最近 500 道，同题干去重）。

入口：**本场记录 → 导出未命中题（N 道）**

- Android 10+ 直接写 `下载/AI答题/未命中题-MMdd-HHmm.txt`，点一次就完事，不用在文件选择器里翻
- 老系统退回系统「另存为」，同样不需要存储权限
- 没有未命中题时按钮置灰
- 导出格式与题库导入器吃的格式一致，可以直接「上传题库文件」补回去
- **无选项的条目不记录也不导出**：导入器要靠选项定位答案文本，缺了只能按字母猜

## 六、验证明细

### JVM 测试（纯逻辑，不依赖真机）

| 用例组 | 断言数 | 结果 |
|---|---|---|
| `TimerDetect`：倒计时/正计时/长文本/普通题面 | 8 | 全 PASS |
| `CloudSolver.orderByHealth`：无样本、连续失败、冷却、解除冷却 | 6 | 全 PASS |
| `MissLog`：存档往返、坏行、判重、导出 → 导入闭环 | 11 | 全 PASS |

其中闭环用例是把 `exportText()` 的产物直接喂给 `Importer`，验证「导出的文件能被自己的解析器完整吃回去」——单选、多选 AB、判断题三种题型都验过。

### 真机（REDMI 192.168.1.113）

- **倒计时误判修正**：`已用 28:39` 修复前显示「限时抢答」，修复后不再显示
- **黄框告警**：智谱 1305 过载 → 悬浮窗 `DeepSeek V4.1-Flash 回答 · 其余厂商没答上来(智谱 GLM 过载)` + **橙色外框**
- **导出链路**：2 道未命中题 → 点导出 → `下载/AI答题/未命中题-1110-1705.txt`（216 字节），内容为可直接导入的题库文本
- **记忆库审核**：同一道题第二次独立作答一致 → 自动转「已确认」，下次 0ms 命中

### 未验证

- 投票「2/3 一致」：智谱整段时间都在 1305，两家都成的场景没跑到
- 老系统（API < 29）的「另存为」分支：本机是 Android 14，走的是直写下载目录

## 七、期间修掉的两个显示 bug

1. **耗时显示 1ms**：投票时 `coreMs = ms - tCloud`，而投票的 `tCloud` 就是全部耗时 → 显示 1ms，像从缓存里蹦出来的。改成「答案出自在线就报在线那段」。
2. **正计时被当成倒计时**：见第一节。
